# RandomFQ

Rikki Ryza F. Sabio
BSIT - 3R4

This "Random Fortune/Quotes Generator" is simple Python program that can be run in the Terminal. This simple program will allow you to receive random quotes or fortune for the day. Some will use this as a pep talk to themselves in the morning, some might use this to prepare for the day, or some just needed something to hear.

++new feature, I added a random color generator for a "lucky color" type of feature where it will pick a color for you.
